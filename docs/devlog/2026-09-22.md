# 2026-09-22 开发日志

## 今日目标

将墨构从单 Markdown 文本框原型推进为以工作区为边界的沉浸式富文本编辑器，并确定三栏写作界面的基础结构。

## 已完成

- 引入最小工作区：正文保存为 `manuscript.html`，工作区配置与每日写作进度保存到 `.mogou/workspace.json`。
- 编辑器升级为所见即所得富文本，支持标题、引用、粗体、斜体、删除线、对齐、列表、分隔线及查找替换。
- 新增 Markdown/TXT 导入与导出；HTML 原稿作为工作区内的唯一格式真相。
- 新增 800ms 防抖自动保存，并在编辑器失焦、切换专注模式和关闭程序时强制保存。
- 新增每日字数目标、当前会话净增字数、写作计时及保存状态反馈。
- 新增 F11、Ctrl+Shift+F 专注模式。
- 完成黑白灰三栏界面：
  - 左栏为资料库/设置标签页，可收起为 48px 图标栏；
  - 中栏上部为编辑工具条，下部编辑器铺满可用区域；
  - 右栏为左右对齐的聊天气泡界面，目前连接本地 Echo 占位服务。
- 工作区的新建、打开、导入、保存和导出统一放入顶部“文件”菜单；资料库仅预留给后续素材管理与 RAG。
- 三栏支持拖动调整比例，并设置最小宽度：左栏 220px、中栏 520px、右栏 280px；禁止拖动导致任一窗格完全消失。

## 设计决策

- 初版继续采用 PySide6 Widgets、`QTextEdit` 与独立 QSS，暂不迁移 QML。
- 工作区内容保持 local-first；向量数据库与 Agent 不进入本轮实现。
- 左栏的按钮收起与分栏拖动分离：按钮收起保留恢复入口，分隔线只负责调整栏宽。
- 富文本原稿使用 HTML，Markdown/TXT 作为导出副本；无法由 Markdown 表达的视觉样式在导出时舍弃并提示。
